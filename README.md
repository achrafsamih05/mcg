# MCG

A modern, responsive web project built with clean HTML, CSS, and PHP.

## 🎨 Project Overview

MCG is a front-end focused web application featuring a professional design implemented with semantic HTML5 and modern CSS styling. The project demonstrates best practices in web development with a focus on responsive design and user experience.

## 🛠️ Technology Stack

- **HTML** (56%) - Semantic structure and markup
- **CSS** (40.7%) - Styling and responsive design
- **PHP** (2.2%) - Server-side functionality
- **JavaScript** (1.1%) - Enhanced interactivity

## ✨ Features

- Responsive and mobile-friendly design
- Clean, semantic HTML structure
- Modern CSS styling with attention to detail
- Server-side processing with PHP
- Lightweight JavaScript implementation

## 🚀 Getting Started

### Prerequisites
- A web server with PHP support
- Modern web browser

### Installation

1. Clone the repository:
```bash
git clone https://github.com/achrafsamih05/mcg.git
cd mcg
```

2. Deploy to your web server or run locally with:
```bash
php -S localhost:8000
```

3. Open your browser and navigate to `http://localhost:8000`
